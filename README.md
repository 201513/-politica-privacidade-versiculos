# Política de Privacidade - Versículos Bíblicos

**Última atualização:** 24 de setembro de 2026

O aplicativo **Versículos Bíblicos** foi desenvolvido como um aplicativo de edificação espiritual gratuito. Esta página é usada para informar os visitantes sobre nossas políticas com a coleta, uso e divulgação de Informações Pessoais, caso alguém decida usar nosso Serviço.

## 1. Coleta e Uso de Informações
Para uma melhor experiência ao usar nosso Serviço, nós **não** exigimos que você crie uma conta ou forneça informações de identificação pessoal (como nome, e-mail, telefone ou endereço). 

## 2. Armazenamento Local de Dados
O aplicativo utiliza o armazenamento interno do seu dispositivo (através do banco de dados Room e SharedPreferences) estritamente para salvar suas preferências locais, tais como:
* Versículos favoritos
* Anotações pessoais
* Progresso nos planos devocionais
* Histórico de leitura e streak (hábito diário)
* Configurações de áudio (TTS) e horários de notificações diárias

Esses dados ficam armazenados **exclusivamente no seu aparelho** e não são enviados para nenhum servidor externo de nossa propriedade.

## 3. Anúncios (Google AdMob)
Nosso aplicativo utiliza o **Google AdMob** para exibir anúncios de banner. O AdMob pode usar identificadores de anúncios do seu dispositivo para exibir anúncios relevantes baseados em seus interesses gerais. Para saber mais sobre como o Google utiliza esses dados, consulte a Política de Privacidade do Google: https://policies.google.com/technologies/ads

## 4. Notificações e Agendamentos
O aplicativo utiliza serviços locais (`WorkManager` e `AlarmManager`) para enviar o versículo diário no horário configurado por você. Nenhuma informação pessoal é coletada durante esse processo.

## 5. Segurança
Valorizamos a sua confiança em nos fornecer seus dados locais. O aplicativo foi projetado seguindo as melhores práticas de segurança do ecossistema Android.

## 6. Alterações a Esta Política de Privacidade
Podemos atualizar nossa Política de Privacidade periodicamente. Assim, é recomendável que você revise esta página regularmente para quaisquer alterações. As alterações entram em vigor imediatamente após serem publicadas nesta página.
